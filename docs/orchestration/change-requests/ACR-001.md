# ACR-001 — Default ansible_user for device-less gate runs

Status: accepted. Baseline: v1 (amendment, not a baseline change).
Date: 2026-09-21. Raised by: ORCHESTRATOR during T-003 V2.

## Context
T-003 V2 (`site.yml --check --diff`) failed before the conflict gate:
every task templates `ansible_user: "{{ vault_lab_user }}"` from
inventories/lab.yml (T-000), and the Vault var is undefined in device-less
runs. Live runs always provide it via Vault; gate/CI runs must not require
a live secret to prove the gate.

## Decision
`inventories/lab.yml`: `ansible_user: "{{ vault_lab_user | default('netaut') }}"`.
Live behavior unchanged (Vault value wins when provided). Device-less runs
get a harmless placeholder; no connection is opened in render-only mode.

## Impact
Amends one line of a T-000-owned file. T-000 stays historical truth; this
record is the authorization. No architecture, contract, or scope change.

## Rollback
Revert the line; V2 then needs `-e vault_lab_user=...` (spec deviation).
