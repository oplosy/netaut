# ACR-005 — Re-open live scope on free Arista cEOS

Status: accepted. Baseline: v1 (scope extension).
Date: 2026-09-22. Raised by: ORCHESTRATOR, decided by: OWNER (in chat).

## Context
ACR-003 dropped live execution because no free, legal IOSv image exists and
the owner will not pay. Arista cEOS-lab is free (free account download),
runs in containerlab and is close to IOS in syntax. Docker and containerlab
already run natively in the owner's WSL Ubuntu.

## Decision
1. Live device execution re-enters scope on cEOS only. This supersedes ACR-003
   decision 1. ACR-003's no-pay rule stays in force.
2. EOS becomes a second vendor through per-role dispatch (INV-003 unchanged).
3. ADR-005 (pre-wave backup) is accepted and implemented by T-011.
4. New tasks: T-008 (EOS render + dispatch), T-009 (lab bring-up), T-010
   (live wave + real post-check), T-011 (backup/restore, HIGH, reviewed).
5. CI stays device-less. The cEOS image cannot be redistributed, so live evidence
   comes from local `make lab-verify` runs committed under reports/.

## Impact
New REQ-009. ADR-006 replaces the deprecated ADR-004. IOS stays render-only and
fails closed in live mode (no live_guard implementation). Routing (T-007)
stays render-only in waves; adding it is a separate, recorded gap.

## Rollback
Revert the T-008..T-011 commits; ACR-003 then applies unchanged.
