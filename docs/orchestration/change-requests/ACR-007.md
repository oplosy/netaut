# ACR-007 — Close the cEOS live-run tasks at project close

Status: accepted. Baseline: v1 (scope reduction).
Date: 2026-09-23. Raised by: ORCHESTRATOR, decided by: OWNER (in chat).

## Context
ACR-006 kept T-009..T-011 BLOCKED on an OWNER corporate Arista account.
The OWNER has none and the project is closing, so the tasks have no path to
DONE. Keeping them BLOCKED would leave an open item that nobody will close.
Their code (cEOS topology, eos inventory, eos `live_guard`) is merged and
covered by CI (render, argspec proof, dry-run, pytest); only the live run on
real cEOS nodes is missing.

## Decision
1. T-009, T-010 and T-011 move to CANCELLED. Task files and state entries
   stay (the code exists and T-011 was reviewed), so history is not rewritten.
2. EOS code, lab files and ADR-006 stay in the repo, unsupported by live
   evidence. SR Linux (ADR-007) is the only live-proven lab.
3. No requirement changes: REQ-009 is met by T-012..T-015 on SR Linux.

## Impact
No open tasks remain. README, runbook and `make LAB=eos` keep working for
anyone holding a cEOS image.

## Rollback
With a cEOS image available, set T-009..T-011 back to PLANNED and run them.
