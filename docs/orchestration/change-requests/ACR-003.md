Date: 2026-09-21. Raised by: ORCHESTRATOR, decided by: OWNER (no-pay decision).

## Context

No free legal source exists and the owner will not pay. T-006 (Containerlab
bring-up) therefore cannot execute; keeping it PLANNED would fake a future
that has no procurement path.

## Decision
1. Live device execution leaves scope (new ASM-007, CONFIRMED).
2. ADR-004 (Containerlab + IOSv lab first) is DEPRECATED, not deleted;
   history stays readable.
3. T-006 task file and state entry are removed (never started, so no
   historical truth is rewritten). Re-adding needs image procurement first.
4. Proof chain stays: hosted CI green + device-less dry runs + stop/rollback
   drill + 13 tests. No claim beyond that is made anywhere.

## Impact

their implementing tasks and verification.
