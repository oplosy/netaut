# ADR-001 — NetBox as source of truth

Status: accepted. Baseline: v1. Date: 2026-09-21.

## Context
Need one writable source for device/interface/prefix/VLAN/VRF/site (REQ-001).

## Decision
NetBox is authoritative; repo holds a versioned YAML export cache for hermetic CI.

## Reason
Single write source kills spreadsheet drift; cache keeps lint/test/dry-run
runnable without live NetBox.

## Consequences
Sync code must handle NetBox outage (fail closed). Re-export procedure documented.

## Rollback
Medium: replace sync with flat YAML SoT; update T-001 owns only.
