# ADR-006 — Containerlab + Arista cEOS lab

Status: accepted (ACR-005). Replaces ADR-004 (deprecated by ACR-003).

## Context
Live waves need a reversible blast radius (ASM-001, OPS-001) at zero cost
(ACR-003 no-pay rule).

## Decision
Containerlab with 2x cEOS (`lab/netaut.clab.yml`, mgmt 172.20.20.0/24),
run from WSL. The image is imported locally by the OWNER and never committed.
Login comes from an encrypted vault under ~/.netaut (INV-001).

## Alternatives rejected
- Nokia SR Linux: free, but its config model is unlike IOS, so the render layer would need a rewrite.
- FRR: free, but routing only (no VLAN/switchport, so phase 2 cannot be tested).
- Cisco IOL via CML-Free: licence terms are ambiguous for this use.

## Consequences
EOS is a second vendor (templates/eos, roles/*/tasks/eos.yml). Live checks
run locally, not in CI. Image version is recorded in each live report.
