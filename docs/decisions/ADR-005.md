# ADR-005 (proposed) — Pre-wave backup enabling live rollback restore

Status: proposed (not accepted). Baseline: v1 untouched.

## Context
`rollback.yml` restores live waves only via a fail-closed assert: no backup
source exists yet. A live wave without restore is a write without an undo.

## Proposal
Before any live wave: fetch `show running-config` per host into
`reports/backups/<host>-<wave>.cfg` (Vault credentials, masked logs), then
deploy. Rollback replays the backup when post-check fails. Drift fixtures
gain a backup-shaped snapshot for CI.

## Cost
One backup role + rollback logic + backup retention note. No model change.

## Activation
Accept only together with a live lab (image procurement first, per ACR-003).
