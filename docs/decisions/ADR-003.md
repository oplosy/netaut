# ADR-003 — Vault-only secrets

Status: accepted. Baseline: v1. Date: 2026-09-21.

## Context
Device credentials must never reach Git or artifacts (INV-001, RISK-002).

## Decision
Ansible Vault + CI masked variables; `no_log: true` on credential tasks; secret scan in CI.

## Reason
Fail-closed secret handling; audit only records requester, never values.

## Consequences
Local runs need vault password workflow; CI needs secret store wiring.

## Rollback
Low: re-key and purge history if violated.
