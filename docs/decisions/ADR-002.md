# ADR-002 — Ansible + Jinja2 with isolated vendor templates

Status: accepted. Baseline: v1. Date: 2026-09-21.

## Context
Must render vendor-compatible configs from one common model (REQ-002, INV-003).

## Decision
Ansible roles hold logic; `templates/<vendor>/` holds only rendering.

## Reason
Team skill fit; pure render function gives idempotency (REQ-005) and testable diffs.

## Consequences
New vendor = new template dir + molecule tests, no role-logic fork.

## Rollback
Medium: template rewrite per vendor.
